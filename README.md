# Toolbox

A curated directory of AI tools for creativity, productivity, learning and development.

**Live site:** https://teahauhnar26.github.io/Toolbox/

## What it does

Toolbox is a personal shelf of AI tools, sorted by what they are good for. It starts with a few well-known tools, and you can shape the rest yourself.

- **Browse by category:** Image Generation, Video Creation, Coding & Dev, Writing & Content, Productivity, Learning & Research, and Other.
- **Collections:** Essential AI Tools, Free AI Tools, For Students, For Creators.
- **Search and filter:** search by name, feature or use case (shortcut: `Ctrl` + `K`), then sort or filter by price and category.
- **Two layouts:** card view or list view.
- **Make it yours:** add your own tools, edit or remove existing ones, and bookmark favourites.
- **Backup:** export your list to a JSON file and import it again later.

## Where your data is stored

Your tool list is saved in your own browser (using `localStorage`). There is no account and no server.

This also means the list belongs to one browser on one device. Clearing your browser data clears the list, so use **Export** to keep a backup.

## How it is built

The whole site is a single file, `index.html`, containing the HTML, CSS and JavaScript together. There is nothing to install and no build step.

- Plain HTML, CSS and JavaScript, with no frameworks
- Fonts: Instrument Serif and Hanken Grotesk, loaded from Google Fonts
- Hosted with GitHub Pages

## Run it on your computer

1. Download `index.html` from this repository.
2. Open it in any web browser.

That is all it needs.
